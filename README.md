# English Data Channel Video Skill

An autonomous Remotion video production skill designed for faceless YouTube channels exploring the real origins of corporate jargon and modern internet slang. It transforms AI voiceovers and timing files into documentary-grade, 2.5D kinetic typography and data-driven motion graphics while strictly avoiding static slideshow templates.

## Key Features

* **Exact Audio-Visual Sync:** Automatically normalizes word or phrase-level timestamps to lock text beats, kinetic punches, and chart animations to the narration.
* **Anti-Slideshow Architecture:** Implements a continuous 2.5D spatial canvas with subtle virtual camera movement, layered architectural grids, and strict zero-overlap QA bounding-box checks.
* **Automated Sound Design & Export:** Synthesizes subtle, consistent SFX cues, mixes an atmospheric background bed beneath the voiceover, and renders verified 1080p 30fps H.264 MP4s.

## Usage

Place `SKILL.md` in your root directory or agent skills folder, then point your coding agent to an episode folder containing the voiceover `.wav` and timing file to generate a complete, verified render.
